WHAT CHANGED
------------
1. COMING UP NEXT event-copy and month-calendar event tiles now have native/deep-link fallbacks instead of depending solely on JavaScript taps.
2. Preview events can open from the full preview feed even when they are outside the month currently displayed.
3. Claimed preview seats open the protected Event Room directly and keep the pink ✓ SEAT CLAIMED · OPEN EVENT treatment.
4. The month-calendar popup no longer performs the protected Zoom workflow; ENTER GATHERING opens the full Event Room.
5. The protected Event Room establishes the Zoom tab synchronously on the user's tap so iOS/mobile popup protection does not make JOIN ZOOM appear dead; same-tab fallback is provided.
6. The Upcoming Events hero copy now says gatherings happen in the Flowtel.
7. Mobile calendar/event-room cards and sheets are tightened to reduce crowding and stack actions vertically.
8. Event artwork uses object-fit: contain across calendar, event details, Upcoming Events, and Lounge/My Upcoming Events so the uploaded graphic is not cropped differently by view.
9. Lounge OPEN EVENT becomes a native protected Event Room link.
10. Lounge OPEN EVENT and ADD TO CALENDAR share consistent action sizing; Lounge actions/calendar choices stack one per row on mobile.
11. This is launch-critical polish only; the larger full mobile information-architecture redesign remains deferred for post-launch.
